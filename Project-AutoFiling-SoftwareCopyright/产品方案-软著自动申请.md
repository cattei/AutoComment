# 产品方案 — 软著自动申请神器

> 更新时间：2026-05-20
> 品牌名：软著申请神器（神器系列 · AutoFiling 子系列）

---

## 一、产品定义

**一句话**：输入项目信息+源码仓库地址，AI自动生成60页操作说明书+60页源代码文档+填表提交中国版权保护中心。

**为什么能做**：
1. 说明书60页是最大痛点 — AI基于源码+README生成，比人写更快更规范
2. 源代码60页截取有固定格式 — 前30页+后30页，自动截取+排版
3. 申请表字段固定 — 软件名称/版本/完成日期/首次发表日期/权利归属
4. 软著申请量暴增 — 2025年中国软著登记量超300万件，年增20%+

## 七、关键发现

1. **说明书是最大痛点** — 60页操作说明书，格式要求严格（页眉/字体/行距），手写1-2天
2. **AI生成说明书质量可控** — 基于源码+README生成，比人写更规范
3. **"一次过"是核心承诺** — 被打回重写是最痛的，AI+格式检查保证合规
4. **批量需求真实** — 软件公司/高校一次申请5-20件，批量折扣有吸引力
5. **毛利率极高** — AI生成文档的边际成本~¥20/件，毛利率~90%
