## 一、产品定位

**一句话**：本地视频翻译配音工具——"拖入中文短剧→选目标语言→一键出译制片"。

**核心差异化**：不是又一个在线视频翻译SaaS，而是**本地离线的视频翻译配音一体机**。所有主流工具（趣丸千音/鬼手剪辑/雅译/HeyGen）都是在线的，需要上传视频到云端。对于内容IP方，上传未公开视频=泄露商业机密。本地=隐私+无限量+断网可用。

**最关键发现**：
1. **在线工具全部需上传视频**——对短剧IP方这是硬伤（未公开内容=商业机密）
2. **开源工具全部需Python环境**——对非技术运营这是天堑
3. **VideoCaptioner不做配音**——字幕≠译制，短剧出海需要的是"翻译+配音+合成"全流程
4. **没有任何产品提供"双击即用的本地视频翻译配音桌面软件"**——这是真空

## 八、技术方案

| 组件 | 选型 | 理由 |
|------|------|------|
| 框架 | Tauri 2.0 | 轻小安装包+Rust性能+跨平台 |
| 语音转录 | whisper.cpp | C++实现，GPU加速成熟，99语言 |
| 翻译引擎 | opus-mt(本地) + NLLB(本地) | opus-mt速度快，NLLB语种多(200+语言) |
| TTS配音 | Edge-TTS(免费) + CosyVoice(开源) | Edge-TTS零成本音质好，CosyVoice支持声音克隆 |
| 声音克隆 | OpenVoice V2 | 10秒参考音频即可克隆，开源 |
| 字幕擦除 | LaMa | 开源最佳 inpainting 模型 |
| 视频合成 | FFmpeg | 烧录硬字幕+替换音轨+合成视频 |
| UI | React + Tailwind | 拖放交互友好 |

**安装包体积预估**：
- 基础包+Whisper Tiny+opus-mt：~200MB
- +CosyVoice模型：~500MB（首次启动可选下载）
- +LaMa模型：~100MB（首次启动可选下载）
- 总计：~800MB（含所有可选模型）

**性能预估**：
- 15分钟短剧字幕翻译：GPU ~3分钟，CPU ~10分钟
- 15分钟短剧+配音+合成：GPU ~8分钟，CPU ~25分钟
- 对比：在线工具通常5-15分钟（含上传下载）
