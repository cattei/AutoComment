## 一、产品定位

**一句话**：隐私优先的本地语音转文字工具 + 实时日转中字幕——"你的语音不离开本机，看日剧不用等字幕组"。

**核心差异化**：
- **基础产品**：不是又一个Whisper套壳，而是面向非技术用户的"零配置隐私转写器"
- **附加模块**：不是又一个在线翻译工具，而是**本地实时日转中字幕悬浮窗**——捕获电脑/手机音频流，Whisper实时转录日语→opus-mt实时翻译→屏幕悬浮中文字幕。全程本地，零延迟，零上传

## 三、实时日转中字幕模块（详细设计）

### 3.1 产品定义

**一句话**：本地实时日转中字幕——"捕获电脑/手机音频流，实时出中文字幕，看日剧/日漫/日游不用等字幕组"。

**核心场景**：

| 场景 | 音频来源 | 典型用户 |
|------|----------|----------|
| 看日剧/日漫（无字幕生肉） | 电脑播放器系统音频 | 二次元/日剧爱好者 |
| 看日本VTuber直播 | 浏览器系统音频 | VTuber观众 |
| 玩日文游戏 | 游戏音频输出 | 主机/PC玩家 |
| 日语会议/网课 | 麦克风或系统音频 | 商务人士/日语学习者 |
| 看日本新闻/综艺 | 手机投屏或系统音频 | 日语学习者 |

### 3.3 技术方案

```
音频流 → [WASAPI CaptureLoopback] → PCM 16kHz
    → [Whisper 流式转录] → 日语文本（~1-2秒延迟）
    → [opus-mt-ja-zh 翻译] → 中文字幕（~0.3秒延迟）
    → [悬浮窗渲染] → 屏幕显示
```

| 组件 | 选型 | 理由 |
|------|------|------|
| 音频捕获 | WASAPI CaptureLoopback (Windows) / CoreAudio (Mac) | 系统级音频捕获，无需麦克风，不受环境噪音影响 |
| 流式ASR | whisper.cpp 流式模式 | C++高性能，GPU加速，日语识别准确率高 |
| 翻译引擎 | opus-mt-ja-zh (ONNX) | 本地离线，日语→中文专用模型，速度快(~300ms/句) |
| 悬浮窗 | Tauri WebView 置顶透明窗口 | 跨平台，可自定义样式，低资源占用 |
| 音频重采样 | libsamplerate / rubato | 48kHz系统音频→16kHz Whisper输入 |

**性能预估**：
- 总延迟：2-3秒（转录1-2秒 + 翻译0.3秒 + 渲染0.1秒）
- CPU占用：~15-25%（Whisper Small模型，无GPU时）
- GPU占用：~10-15%（CUDA加速时）
- 内存：~500MB-1GB（Whisper Small + opus-mt）

**与竞品的延迟对比**：
- 在线工具（Live Subtitles等）：3-5秒（含网络往返）
- 华为AI字幕：1-2秒（但仅华为设备）
- 本工具：2-3秒（纯本地，无网络延迟）

**最关键发现**：
1. **华为AI字幕已验证"实时日转中字幕"需求成立**——但它锁死在华为设备
2. **Live Subtitles已验证"系统音频→实时字幕"商业模式成立**——但它在线+订阅
3. **所有开源工具需Python/配置**——非技术用户无法使用
4. **没有任何产品提供"双击即用的本地实时日转中字幕桌面工具"**——这是真空

## 八、技术方案（整体产品）

| 组件 | 选型 | 理由 |
|------|------|------|
| 框架 | Tauri 2.0 | 轻小安装包(10MB)+Rust性能+跨平台 |
| 转写引擎 | whisper.cpp | C++实现，比Python快3-5倍，GPU加速成熟 |
| 模型 | Whisper Tiny/Base/Small/Medium | 按需下载，Tiny仅75MB，Medium1.5GB |
| **音频捕获** | **WASAPI CaptureLoopback (Win) / CoreAudio (Mac)** | **系统音频捕获，无需麦克风** |
| **翻译引擎** | **opus-mt-ja-zh (ONNX)** | **本地离线日转中，速度快(~300ms/句)** |
| **悬浮窗** | **Tauri WebView 置顶透明窗口** | **可拖拽/调样式/低资源占用** |
| 说话人识别 | pyannote-audio (ONNX) | V2功能，开源最佳 |
| UI | React + Tailwind | 简洁现代，Tauri原生支持 |
| 安装包 | NSIS(Windows) / dmg(Mac) | 一键安装，无需配置环境 |

**安装包体积预估**：
- 基础包（不含模型）：~15MB
- +Tiny模型：~90MB
- +Base模型：~150MB
- +Small模型：~500MB
- +opus-mt-ja-zh翻译模型：~300MB（日转中字幕模块附带）
- 首次启动引导下载模型，不打包在安装包中

## 九、风险与应对

| 风险 | 概率 | 应对 |
|------|:---:|------|
| Vibe快速改进UX，抹平差异化 | 中 | 持续迭代UX+隐私营销+实时字幕是Vibe不会做的 |
| 讯飞降价/增加免费额度 | 中 | 永久授权vs订阅的性价比优势长期存在 |
| MacWhisper推出Windows版 | 低 | 即使做，€64(¥500) vs ¥49仍有价格优势；且无实时字幕 |
| 华为AI字幕开放给所有Windows | 低 | 华为AI字幕是硬件卖点，不会开放；且不可自定义+无术语表 |
| Live Subtitles降价/推本地版 | 中 | 它是SaaS商业模式，本地版与订阅冲突 |
| LiveSub等开源工具改进UX | 中 | 开源迭代慢；Tauri原生永远更轻更快 |
| 日转中翻译质量不够好 | 中 | opus-mt-ja-zh是专用日中模型，质量已不错；V2可升级为NLLB或本地LLM翻译 |
| Whisper实时转录延迟过高 | 中 | Small模型GPU下~1-2秒可接受；可提供Tiny选项(更快但略不准) |
| 二次元用户付费转化率低 | 中 | ¥19是"奶茶价"；且二次元为爱好付费意愿实际较强(手办/会员/游戏氪金) |

## 十一、产品架构总览

```
┌─────────────────────────────────────────────────┐
│              语音转文字桌面工具                     │
├─────────────────────┬───────────────────────────┤
│   核心模块（免费+付费）  │   附加模块（付费）          │
├─────────────────────┼───────────────────────────┤
│ · 拖入文件转写        │ · 实时日转中字幕            │
│ · 多语言转录(99语)    │   - 系统音频捕获           │
│ · 多格式导出          │   - Whisper实时日语转录     │
│ · 批量处理           │   - opus-mt日转中翻译       │
│ · 说话人识别          │   - 悬浮字幕窗             │
│ · AI摘要            │   - 字幕样式自定义          │
│ · 隐私大字报          │   - 术语表                 │
└─────────────────────┴───────────────────────────┘
```

**模块关系**：
- 核心模块独立可用，不依赖附加模块
- 日转中字幕模块依赖核心模块的Whisper引擎（共用模型）
- 两者共享：Tauri框架、Whisper引擎、GPU加速、隐私叙事
- 日转中字幕模块的翻译引擎(opus-mt-ja-zh)是独立组件，核心模块不需要
