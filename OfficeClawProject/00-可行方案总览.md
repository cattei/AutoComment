## 二、🥇 视频翻译（跨境）— 78分



### 产品定义



**一句话**：拖入中文短剧→选目标语言→一键出译制片。本地离线，IP不离开本机。



### 功能清单



#### MVP — 字幕翻译线



| 功能 | 说明 | 优先级 |

|------|------|:---:|

| 视频语音转录 | Whisper本地转录，99语言 | P0 |

| 字幕翻译 | opus-mt/NLLB本地翻译，30+语对 | P0 |

| 双语字幕生成 | 原文+译文SRT/VTT/ASS | P0 |

| 硬字幕烧录 | FFmpeg嵌入硬字幕，可选样式/位置 | P0 |

| 字幕擦除 | LaMa模型擦除原硬字幕（短剧常见） | P1 |

| 批量处理 | 一次拖入多集，队列翻译 | P1 |

| GPU加速 | CUDA自动检测 | P0 |



#### V2 — 配音线



| 功能 | 说明 | 优先级 |

|------|------|:---:|

| AI配音(TTS) | Edge-TTS/CosyVoice本地语音合成 | P0 |

| 多角色配音 | 区分说话人，分配不同音色 | P0 |

| 声音克隆 | 提供10秒参考音频克隆原声（基于OpenVoice） | P1 |

| 配音+视频合成 | 替换原音轨+合成新视频 | P0 |

| 音色库 | 20+内置音色（男/女/年轻/成熟/多语言） | P1 |

| 语速/音调调节 | 滑块调节配音语速和音调 | P2 |



#### V3 — 专业线



| 功能 | 说明 | 优先级 |

|------|------|:---:|

| 口型同步 | Wav2Lip/GeneFace唇形同步 | P1 |

| 术语库 | 短剧/电商/教育行业术语自定义 | P1 |

| 多市场一键出 | 同一视频一键生成英/日/韩/泰/越/西/阿7个版本 | P1 |

| 字幕校对编辑器 | 可视化双语对照编辑+时间轴微调 | P2 |

| 命令行批量 | CLI批量处理，支持自动化流水线 | P2 |



### 需求分析



| 用户群 | 占比 | 核心需求 | 现状痛点 | 付费理由 |

|--------|:---:|----------|----------|----------|

| 短剧出海团队(3-20人) | 45% | 月产50-100集需译制 | 趣丸千音门槛高+按量贵；鬼手剪辑¥0.2/分但需上传(IP泄露) | ¥129永久=1月回本(鬼手¥150/月) |

| 跨境电商(TikTok/Amazon) | 30% | 商品视频多语言版本 | HeyGen¥12.99/月仅英文好；在线翻译=泄露选品信息 | 本地=选品不泄露+无限量 |

| 教育/企业/自媒体 | 25% | 课程/培训/宣传视频翻译 | 在线工具需上传+按量计费 | 本地+永久授权 |



### 对标竞品



| 竞品 | 类型 | 定价 | 你的差异化 |

|------|------|------|------------|

| 趣丸千音 | 在线SaaS | 企业版按量 | 本地=IP安全+无限量 |

| 鬼手剪辑 | 在线SaaS | ¥0.2/分钟 | 本地=IP安全+永久授权 |

| pyvideotrans | 开源Python | 免费 | 双击即用，无需Python |

| VideoCaptioner | 开源桌面 | 免费 | VideoCaptioner不做配音，你做"翻译+配音+合成"全流程 |

| HeyGen | 在线SaaS | ¥12.99/月 | 本地+多语言+配音 |



### 关键发现



1. **短剧出海爆发**：2025年中国短剧App占全球下载80%+，AI译制成行业刚需

2. **在线工具全需上传视频→IP泄露硬伤**；开源工具全需Python→非技术用户天堑

3. **没有任何产品提供"双击即用的本地视频翻译配音桌面软件"**——真空

4. VideoCaptioner不做配音→字幕≠译制，短剧出海需要"翻译+配音+合成"全流程

#### MVP



| 功能 | 说明 | 优先级 |

| 拖入即抠图 | 拖入单张图片，1秒出透明PNG | P0 |

| 批量抠图 | 拖入文件夹，自动处理所有图片 | P0 |

| 多格式输入 | JPG/PNG/WEBP/BMP/TIFF/HEIC | P0 |

| 多格式输出 | 透明PNG(默认)/白底JPG/自定义纯色背景 | P0 |

| 模型选择 | RMBG-2.0(精准)/RMBG-1.4(快速) 两档 | P0 |

| 输出尺寸 | 保持原尺寸/自定义尺寸/电商主图800×800 | P0 |

### 需求分析



| 用户群 | 占比 | 核心需求 | 现状痛点 | 付费理由 |

|--------|:---:|----------|----------|----------|

| 中小电商运营(日处理20-150张) | 55% | 每天上新/做活动要抠大量商品图 | remove.bg 50张/月不够；抠图喵9张/次太慢；请美工¥5-15/张 | ¥39永久=无限量抠图 |

| 服装/珠宝/家居(复杂边缘) | 25% | 薄纱/蕾丝/毛边/玻璃器皿抠图 | 普通抠图边缘锯齿/残留；PS钢笔15-30分/张 | RMBG-2.0精度90.14%>remove.bg |

| 设计师/摄影师 | 20% | 批量抠图+换背景 | PS手动抠慢；在线工具限免 | 本地+批量+PSD导出 |



### 对标竞品



| 竞品 | 定价 | 你的差异化 |

|------|------|------------|

| remove.bg | 50张/月免费+付费 | 你本地无限量+¥39永久 |

| 抠图喵(小程序) | 免费9张/次 | 你无限量+桌面批量+更精准 |

| 美图秀秀 | 免费 | 你更精准(RMBG-2.0)+专业批量+电商模板 |

| RMBG-2.0(开源) | 免费 | 你双击即用，无需Python |

| 淘宝抠图软件 | ¥2.88 | 你更精准+更专业+品牌可信 |



### 关键发现



1. **免费方案有硬限制**：抠图喵9张/次、remove.bg 50张/月——重度用户被逼付费

2. **RMBG-2.0精度90.14%>remove.bg**——技术上有优势，但需Python部署

3. **淘宝¥2.88/700+人付款**——验证需求但锚定极低价格

4. 电商日处理50+张的运营，¥39永久是刚需不是可选
