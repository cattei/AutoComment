## 一、产品定位

**一句话**：电商运营的本地无限批量抠图工具——"拖入文件夹→一键抠图→导出透明PNG"。

**核心差异化**：不是又一个在线抠图网站，而是**解决"RMBG-2.0精度高但部署难"的痛点**——把开源最强抠图模型打包成双击即用的桌面软件，让不会装Python的电商运营也能用上本地无限批量抠图。

## 七、技术方案

| 组件 | 选型 | 理由 |
|------|------|------|
| 框架 | Tauri 2.0 | 轻小安装包+Rust性能+跨平台 |
| 抠图引擎 | ONNX Runtime | RMBG-2.0模型ONNX格式，CPU/GPU自动切换 |
| 模型 | RMBG-2.0(BiRefNet) + RMBG-1.4 | 精准档90.14%准确率，快速档速度3x |
| 图像处理 | Sharp(Rust) | 格式转换+压缩+缩放，Rust极速 |
| UI | React + Tailwind | 简洁现代，拖放交互友好 |
| 安装包 | NSIS(Windows) / dmg(Mac) | 一键安装，模型内置或首次启动下载 |

**安装包体积预估**：
- 基础包+RMBG-1.4模型：~80MB
- +RMBG-2.0模型：~200MB（首次启动可选下载）
- 对比：美图秀秀几百MB，你的80MB是轻量优势

**性能预估**（基于RMBG-2.0实测数据）：
- 单张抠图：GPU 0.08-0.5秒，CPU 1-3秒
- 批量100张：GPU ~1分钟，CPU ~5分钟
- 对比：PS手动 15-30分钟/张
