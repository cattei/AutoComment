# 产品方案 — 自动申请神器系列

> 更新时间：2026-05-20
> 核心逻辑：凡是需要"填写表单+提交材料+等待审核"的重复流程，都可以用AI+自动化替代

---

## 一、核心洞察

**一句话**：中国有大量"申请制"流程，每个都需要填表+传材料+等审核，AI可以自动填表+生成材料+追踪进度。

**为什么现在能做**：
1. **AI能生成申请材料** — 软著说明书、专利申请书、ICP备案材料，AI写比人写更快更规范
2. **浏览器自动化成熟** — Playwright/Puppeteer能自动填表+上传+提交
3. **OCR+结构化** — 身份证/营业执照/代码截图，AI能自动识别和结构化
4. **需求真实且痛** — 每个申请流程都是重复劳动，但没人做自动化

## 三、重点深挖：软件著作权自动申请

这是第一梯队最值得先做的产品。

### 产品定义

**一句话**：输入项目信息+源码仓库地址，AI自动生成60页说明书+60页源代码+填表提交中国版权保护中心。

**品牌名**：软著申请神器（神器系列成员）

### 功能清单

#### MVP

| 功能 | 说明 | 优先级 |
|------|------|:---:|
| 项目信息录入 | 软件名称/版本/完成日期/首次发表日期 | P0 |
| 源码导入 | 本地目录/Git仓库URL，自动统计行数 | P0 |
| AI生成说明书 | 根据源码+README自动生成60页操作说明书 | P0 |
| 源代码截取 | 自动截取前30页+后30页源代码（符合格式要求） | P0 |
| 说明书排版 | 按版权中心要求排版（页眉/页脚/字体/行距） | P0 |
| 材料检查 | 自动检查材料完整性+格式合规性 | P0 |
| PDF导出 | 说明书+源代码导出为符合要求的PDF | P0 |
| 申请表填写 | 自动填写软件著作权登记申请表 | P1 |

#### V2

| 功能 | 说明 | 优先级 |
|------|------|:---:|
| 在线提交 | 自动登录版权保护中心网站提交 | P0 |
| 进度追踪 | 提交后自动查询审核进度 | P0 |
| 批量申请 | 一次导入多个项目，批量生成材料 | P1 |
| 证书管理 | 证书到期提醒+续展 | P1 |
| 模板库 | 常见软件类型说明书模板 | P2 |

### 需求分析

| 用户群 | 占比 | 核心需求 | 现状痛点 | 付费理由 |
|--------|:---:|----------|----------|----------|
| 独立开发者 | 35% | 个人项目申请软著（APP上架/政策补贴需要） | 说明书60页写1-2天，格式容易被打回 | ¥199=省2天时间 |
| 软件公司 | 30% | 每个产品/版本都要申请 | 专人写说明书，效率低 | 批量¥99/次 |
| 高校/科研 | 20% | 科研成果软著（职称/项目结题需要） | 不懂格式要求，反复被打回 | AI保证一次过 |
| 外包公司 | 15% | 交付物需要软著 | 每个项目都写，重复劳动 | 批量折扣 |

### 对标竞品

| 竞品 | 类型 | 定价 | 你的差异化 |
|------|------|------|------------|
| 代理机构 | 人工服务 | ¥500-2000/件 | 你¥199/次，AI生成+自动提交 |
| 权大师/八戒知识产权 | 在线平台 | ¥300-800/件 | 你AI生成说明书，他们只帮你提交 |
| 自己写 | DIY | 免费（但2天时间） | 你30分钟搞定，省2天 |

### 关键发现

1. **软著申请量暴增** — 2025年中国软著登记量超300万件，年增20%+
2. **说明书是最大痛点** — 60页操作说明书，格式要求严格（页眉/字体/行距），手写1-2天
3. **AI生成说明书质量可控** — 基于源码+README生成，比人写更规范
4. **"一次过"是核心承诺** — 被打回重写是最痛的，AI+格式检查保证合规
5. **批量需求真实** — 软件公司/高校一次申请5-20件，批量折扣有吸引力

**插件化设计**：每种申请类型是一个插件，包含：
- 材料清单定义
- AI Prompt 模板（生成各类文档）
- 表单字段映射
- 提交流程自动化脚本
- 审核进度查询接口
